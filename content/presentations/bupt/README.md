# 连接世界，从北邮出发

北京邮电大学 12 页 HTML 演示。作品集地址：`/bupt/`。

直接打开 `index.html` 即可离线演示，或在仓库根目录运行 `npm run dev`。
本目录的图片、字体、样式和脚本齐全，分享时请发送整个目录；资源全部使用本地相对路径，无外部字体、图片 CDN 或 JavaScript 依赖。

- 信息页分组渐入；摄影页方向性展开与轻微景深；所有动画完成后静止供讲解。
- 第三页：进度线约两秒走过五个节点，节点点亮后依次带出年份与说明。
- 29,000+、54、200+ 自动计数，点击数字可重播。年份与 6G 不作计数。
- ↻ 按钮或 R：重播本页；方向键 / 空格：翻页；O：目录；F：全屏；Home / End：首末页。
- 手机左右滑动翻页，长页纵向滚动。减少动态模式显示完整静态内容；打印显示全部十二页及最终数字。
- [逐页解说稿](解说稿.md)：约 7–8 分钟，含演示停顿提示。

## 设计与动效

深海蓝 `#092438`、暖白 `#F4F1EA`、青绿 `#75C7BA`。本地 Noto Serif CJK SC / Noto Sans CJK SC 字体子集，许可证见 `assets/FONT-LICENSE.txt`。

按照 web-design-engineer 的编辑式层级、motion-web 的转场节奏与可访问性，以及 onetake 的承接和停顿原则制作。持续页码轨道与信号进度线贯穿演示；仅翻页时运动，静止阅读时不播放背景动画。未使用 onetake 源码，无自动播放视频或配乐。

校情数据来自官网更新至 2026 年 5 月的学校简介；科研页引用 2026 年 9 月 28 日的官方新闻。资料检索日为 2026 年 10 月 3 日。所有资料链接见第十二页；图片原始地址见 `assets/sources.json`。图片及校标的原版权归校方或摄影者，本作品为独立校情介绍，不代表校方。
